# Healthcare-Management-System

A Java-based Healthcare Management System built with Eclipse IDE. Streamlines hospital workflows including patient registration, doctor management, appointment scheduling, and billing operations. Designed with clean code architecture for efficient and reliable healthcare administration.

## 🛠️ Tech Stack
- **Language:** Java
- **IDE:** Eclipse
- **Framework:** Spring Boot
- **Database:** MySQL
- **ORM:** Hibernate / Spring Data JPA
- **Build Tool:** Maven
- **Frontend:** HTML5, CSS3, JavaScript

## 🔄 Workflow
1. **Patient Registration** — New patient details add பண்ணி records create ஆகும்
2. **Doctor Management** — Doctor profiles, specialization, availability manage பண்ணலாம்
3. **Appointment Scheduling** — Patient ↔ Doctor appointment book & track பண்ணலாம்
4. **Billing Operations** — Treatment charges calculate பண்ணி bill generate ஆகும்
5. **Admin Dashboard** — எல்லா operations-உம் ஒரே place-ல manage பண்ணலாம்

## 📌 Features
- Patient registration & profile management
- Doctor scheduling & availability tracking
- Appointment booking system
- Billing & invoice generation
- Role-based access (Admin / Doctor / Patient)
